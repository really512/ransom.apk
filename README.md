# R4NS0M Simulator

Безопасный визуальный симулятор ransomware для тестирования интерфейса.

## Что делает

- показывает экран-имитацию ransomware;
- отображает таймер и игровую валюту;
- имитирует состояние «файлы зашифрованы» только визуально;
- **не шифрует, не удаляет и не изменяет пользовательские файлы**;
- не требует доступа к файлам устройства.

Текущий архив симулятора: `r4ns0m-simulator-1.2.0.zip`.

## Важно

Это учебная/демонстрационная программа. Любые действия с реальными файлами намеренно отсутствуют.
